## 🌟 What is this branch?

This `react` branch contains the standalone, production-ready React 19 application configured specifically for zero-config **Netlify** continuous deployment.

### 🚀 Key Features on this Branch:
1. **Interactive Visitor Welcome Modal (`ProjectInfoModal.jsx`)**:
   - Automatically welcomes visitors to the live site.
   - Summarizes how this design connects to the **WordPress** and **Shopify** versions.
   - Features a direct one-click button leading back to the [GitHub Repository](https://github.com/mdsiam2007/OWEK-Theme).
   - Includes a non-intrusive floating trigger badge (`⚡ Project Info & GitHub`) in the bottom-right corner to reopen the modal anytime.
2. **Netlify Optimization**:
   - Root-level `netlify.toml` with Single Page Application (SPA) redirect rules (`/* -> /index.html 200`).
   - Lightning-fast production build output using Vite 6.

## 💻 Local Development

```bash
# 1. Install dependencies
npm install

# 2. Run local development server (HMR enabled)
npm run dev

# 3. Create production bundle
npm run build

# 4. Preview production build locally
npm run preview
```

## 🌐 Deploying to Netlify in 30 Seconds

1. Go to [Netlify App](https://app.netlify.com/).
2. Click **Add new site ➔ Import an existing project**.
3. Select **GitHub** and authorize your repository: `mdsiam2007/OWEK-Theme`.
4. In **Branch to deploy**, select: **`react`**.
5. Netlify will automatically detect:
   - **Base directory**: `/`
   - **Build command**: `npm run build`
   - **Publish directory**: `dist`
6. Click **Deploy Site** — your live site will be online with the interactive popup modal!
